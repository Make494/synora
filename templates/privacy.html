Нууцлал анхнаасаа

Энэ прототип байнгын хадгалалтгүйгээр ажиллах боломжтой. Хадгалалт асаалттай үед зөвшөөрөл шаардана.

Ямар мэдээлэл цуглуулах вэ?

Үнэлгээ хийх үед хүүхдийн нас (сараар), Q-CHAT-10 асуултын сонгосон хариулт болон тооцсон оноог боловсруулна. Тусдаа, хяналттай судалгааны API нь tracking_ratio, ball_visible_rate, pointing_rate, eyes_rate, face_rate болон Age гэсэн зургаан тоон утгыг хүлээн авч загвараар боловсруулдаг; эдгээр feature-ийг энгийн хэрэглэгчээс асуухгүй. Камерын frame-үүдийг зөвхөн браузер дотор түр боловсруулна. Видео, нүүрний дүрс болон 5 цэгийн калибровкийн дээж сервер рүү дамжуулахгүй, бичлэг хийхгүй. Үр дүнг харуулах шаардлагатай бол зөвхөн ойролцоо чиглэлийн тооллыг browser sessionStorage-д түр уншаад үр дүнгийн хуудсанд харуулсны дараа цэвэрлэнэ. Камер зогсоох, төхөөрөмж солих эсвэл хуудсыг хаахад калибровкийн дээж арилна. MediaPipe-ийн runtime болон model asset нь CDN/Google эх сурвалжаас татагдана; эдгээрт камерын дүрс илгээхгүй.

Мэдээллийг ямар зорилгоор ашиглах вэ?

Q-CHAT-10 хариултыг асуулгын оноо харуулахад ашиглана. Нэгдсэн үнэлгээнд eye-tracking мэдээллийг зөвхөн browser-side туршилтын тойм хэлбэрээр тусад нь харуулна; одоогийн хэмжилт судалгааны загварын яг шаардах зургаан feature биш тул prediction үүсгэхгүй. Судалгааны API загварыг Q-CHAT-10 хариултаас тооцоолдоггүй бөгөөд үр дүн нь эмнэлзүйн онош биш.

Мэдээлэл хадгалагдах уу?

Асран хамгаалагчийн эхлүүлэх зөвшөөрөл нь Q-CHAT-10 үр дүн болон браузер дотор түр тооцсон тоймыг тухайн үнэлгээний сессэд боловсруулахыг хамарна; camera consent тусдаа. Камерын зураг, video болон калибровкийн samples серверт хадгалагдахгүй. Анхдагч тохиргоогоор асуулгын хариултыг байнга хадгалахгүй; Firebase тохируулж идэвхжүүлсэн тохиолдолд өгөгдөл хадгалах тусдаа зөвшөөрөл шаардана. Судалгааны endpoint-ийн feature хүсэлтийг session эсвэл Firebase-д хадгалдаггүй.

Зөвшөөрөл ба устгах хүсэлт

Хадгалалтад зөвшөөрөх нь сонголттой бөгөөд үнэлгээг хийхэд зайлшгүй шаардлагагүй. Firebase хадгалалт идэвхжсэн орчинд өмнө хадгалсан мэдээллийг устгуулах хүсэлтийг тухайн төслийн хариуцагчид хандана. Энэ демо хувилбарт хүсэлт хүлээн авах тусгай холбоо барих суваг тохируулаагүй; хадгалалт ашиглалтад оруулахаас өмнө ийм сувгийг эзэмшигч тохируулах шаардлагатай.

Эмнэлгийн оношилгоо биш

Synora нь эмнэлгийн оношилгооны үйлчилгээ биш бөгөөд эрүүл мэндийн нууцлалын хууль, стандартын нийцэл эсвэл аюулгүй байдлын гэрчилгээтэй гэж мэдэгдэхгүй. Эрүүл мэндийн асуудлаар мэргэжлийн эмчтэй зөвлөлдөнө үү.
